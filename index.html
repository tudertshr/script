1.1 Introduction à l'Algorithmique

Algorithme : Suite finie et ordonnée d'instructions permettant de résoudre un problème spécifique.

Caractéristiques d'un bon algorithme :

  • Précis : Instructions non ambiguës
  • Fini : S'arrête après un nombre fini d'étapes
  • Efficace : Utilise optimalement les ressources
  • Compréhensible : Facile à comprendre et modifier

Différence Algorithme/Programme :

  • Algorithme : Solution conceptuelle, indépendante du langage
  • Programme : Implémentation concrète dans un langage spécifique

1.2 Concepts des Langages de Programmation

Langages Compilés vs Interprétés :

Type Exemples Processus Avantages Inconvénients
Compilé C, C++, Java Code source → Compilateur → Code machine (exécutable) Rapide à l'exécution Dépendant de la plateforme
Interprété Python, JavaScript, PHP Code source → Interpréteur → Exécution ligne par ligne Portable, facile à déboguer Plus lent à l'exécution

Éléments d'un langage :

  • Lexique : Ensemble des mots-clés, identificateurs, opérateurs
  • Syntaxe : Règles de composition des instructions
  • Sémantique : Signification des constructions syntaxiques

Types d'erreurs :

  1. Erreurs de syntaxe : Violation des règles grammaticales (détectées par le compilateur/interpréteur)
  2. Erreurs sémantiques : Instructions syntaxiquement correctes mais logiquement fausses
  3. Erreurs d'exécution : Problèmes pendant l'exécution (division par zéro, dépassement mémoire)

1.3 Types de Données et Variables

Types de base :

  • Entier (int) : Nombres sans virgule
  • Réel (float) : Nombres avec virgule
  • Chaîne (string) : Suite de caractères
  • Booléen (bool) : Vrai/Faux

Déclaration et affectation :

Python 
# Python (typage dynamique)
nom_variable = valeur
C 
// C (typage statique)
type nom_variable;

Opérateurs :

  • Arithmétiques : + - * / %
  • Comparaison : == != < > <= >=
  • Logiques : and or not (Python), && || ! (C)

1.4 Structures de Contrôle

Structure conditionnelle :

Python

Structures répétitives :

Boucle while (tant que) :

Python 
while condition:
    # instructions répétées

Python

1.5 Structures de Données Complexes

Tableaux (Vecteurs) :

  • Collection d'éléments de même type
  • Accès par indice (commençant à 0 en Python/C, à 1 en algorithmique)
  • Taille fixe ou dynamique selon le langage

Déclaration :

Algorithmique 
Tableau T[1..N] d'entiers
Python 
T = [0] * N  # Tableau de N zéros
C 
int T[N];  // Tableau de N entiers

Matrices (Tableaux bidimensionnels) :

  • Tableau de tableaux
  • Accès par deux indices : M[i][j] (ligne i, colonne j)

Chaînes de caractères :

  • Tableau de caractères terminé par \0 en C
  • Type dédié en Python avec méthodes intégrées

1.7 Bonnes Pratiques et Conseils

Bonnes Pratiques :

  1. Indentation : Cruciale en Python (4 espaces par niveau)
  2. Nommage : Variables explicites (somme plutôt que s)
  3. Commentaires : Expliquer le "pourquoi" pas le "comment"
  4. Modularité : Décomposer en petites fonctions
  5. Tests : Vérifier avec des cas simples d'abord

Erreurs Courantes :

  • Oubli des deux-points après if, for, while, def
  • Confusion = et == : = pour l'affectation, == pour la comparaison
  • Indices hors limites dans les tableaux
  • Boucles infinies : Condition de sortie manquante
  • Division par zéro : Toujours vérifier le dénominateur

Conseils pour les Examens :

  1. Lisez attentivement l'énoncé
  2. Identifiez les entrées/sorties
  3. Décomposez le problème en sous-problèmes
  4. Testez avec des valeurs simples
  5. Vérifiez les cas limites
  6. Commentez votre raisonnement

Factorielle avec fonction
Fonctions Ex 1

Énoncé : Écrire une fonction qui calcule la factorielle d'un nombre n.

Solution Python :

Python 
def factorielle(n):
    """Calcule la factorielle de n"""
    if n == 0:
        return 1
    
    resultat = 1
    for i in range(1, n + 1):
        resultat *= i
    
    return resultat

# Test de la fonction
n = int(input("Nombre : "))
print(f"{n}! = {factorielle(n)}")
Vérification nombre premier
Fonctions Ex 2

Énoncé : Écrire une fonction qui vérifie si un nombre est premier.

Solution Python :

Python 
def est_premier(n):
    """Vérifie si n est un nombre premier"""
    if n < 2:
        return False
    
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    
    return True

# Test de la fonction
nombre = int(input("Nombre : "))
if est_premier(nombre):
    print(f"{nombre} est premier")
else:
    print(f"{nombre} n'est pas premier")

Algorithmes Avancés

Tri par bulles
Algo 1

Principe : Balayer tout le tableau, en comparant les éléments adjacents et les échangeant s'ils ne sont pas dans le bon ordre.

Solution Python :

Python 
def tri_bulles(tableau):
    """Trie un tableau par la méthode des bulles"""
    n = len(tableau)
    
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if tableau[j] > tableau[j + 1]:
                # Échange des éléments
                tableau[j], tableau[j + 1] = tableau[j + 1], tableau[j]
    
    return tableau

# Test de l'algorithme
T = [5, 2, 8, 1, 9, 3]
print("Avant tri :", T)
print("Après tri :", tri_bulles(T.copy()))
Recherche dichotomique
Algo 2

Principe : Recherche efficace dans un tableau trié en divisant l'espace de recherche par deux à chaque étape.

Solution Python :

Python 
def recherche_dichotomique(tableau, valeur):
    """Recherche dichotomique dans un tableau trié"""
    gauche = 0
    droite = len(tableau) - 1
    
    while gauche <= droite:
        milieu = (gauche + droite) // 2
        
        if tableau[milieu] == valeur:
            return milieu  # Élément trouvé
        elif tableau[milieu] < valeur:
            gauche = milieu + 1  # Recherche dans la moitié droite
        else:
            droite = milieu - 1  # Recherche dans la moitié gauche
    
    return -1  # Élément non trouvé

# Test de l'algorithme
T_trie = [1, 3, 5, 7, 9, 11, 13]
valeur = int(input("Valeur à rechercher : "))
position = recherche_dichotomique(T_trie, valeur)

if position != -1:
    print(f"{valeur} trouvé à la position {position}")
else:
    print(f"{valeur} non trouvé")
